## 2\. Bookable Days

Phone Booking will not enforce the [**Booking Window**](/booking-calendar-time-slot-settings#BookingWindow/) if it is set to use **Bookable days**.

## 3\. Categories for Booking Hubs

Phone Booking **ignores the hierarchical structure of Categories** within the Booking Hub, allowing the guests to book directly via the individual Booking Calendars.
