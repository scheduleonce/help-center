Integrating OnceHub with Keragon, an Integration Platform as a Service (iPaaS) enables you to automate data movement between OnceHub and specialized healthcare applications.

This connection allows you to securely sync scheduling data with Electronic Health Records (EHRs), medical CRMs, and over 300 clinical tools. It is an ideal solution for healthcare organizations looking to automate patient journeys while maintaining the highest security and compliance standards.

<Aside type="note">
  For more information on supported workflows and healthcare connectors, visit
  the [**OnceHub integration page on
  Keragon**](https://www.keragon.com/integrations/oncehub).
</Aside>

---

## Key Features of the Keragon Integration

The OnceHub integration with Keragon enables healthcare-specific automation through the following core capabilities:

- **HIPAA-Compliant Patient Workflow Automation:** Securely automate the movement of sensitive scheduling data between OnceHub and your clinical toolset (EHR/ EMR) on an iPaaS purposely built for healthcare privacy.
- **AI-Assisted Coordination:** Use natural language and AI-powered configuration to build complex automated workflows for patient onboarding, intake, and secure communication without the need for manual coding.

---

## Connecting OnceHub with Keragon

To set up the integration, you will need to authorize the connection using your **OnceHub API Key**.

1. Click the **gear icon** located in the top-right corner of the page.
2. Select **Account Integrations** from the dropdown menu.
3. Filter for **Automation**.
4. Click the **Keragon** tile.
5. Click on **Set up on Keragon**.
6. Follow the on-screen setup instructions to authorize the connection using your [**OnceHub API Key**](/account-integrations/automation/api-and-webhooks/api-key-security-management).

---

## Available Actions in the Keragon Platform

Once connected, you can utilize the following on-demand actions to automate your scheduling and healthcare workflows:

| **Action**       | **Description**                                                       |
| ---------------- | --------------------------------------------------------------------- |
| **Get Bookings** | Retrieves a list of all scheduled meetings from your OnceHub account. |
| **Get Users**    | Retrieves a list of all users from your OnceHub account.              |
| **Get Contacts** | Retrieves a list of all contacts from your OnceHub account.           |
