Automatically add and delete users in OnceHub directly from Entra ID using SCIM. This provides real-time synchronization ensuring that user access is always up to date, reducing administrative overhead and enhancing security.

This article guides you through the process of establishing a SCIM integration between OnceHub and Entra ID.

## Step 1: Create a New OnceHub Application in Entra ID

In Entra ID, follow the steps below to create a new SCIM application integration:

1. Select **Enterprise apps** from the left navigation menu.
2. Click **New application** in the top left of the screen.
3. Click **Create your own application** in the top left of the screen.
4. Provide a name for the app.
5. Select **Integrate any other application you don’t find in the gallery (Non-gallery)**.
6. Click **Create**.

---

## Step 2: Configure the OnceHub Application Settings in Entra ID

Next, you will need to add your OnceHub details to the application you created in Entra ID.

### Finding the Integration Details within OnceHub

In OnceHub, follow these steps to open the **Entra ID** integration view with the required details:

1. Click the gear icon in the top right corner.
2. Select **Account Integrations** from the dropdown
3. Filter for **Security and Compliance**.
4. Click the **Microsoft Entra ID** tile.

<Aside type="note">

&#x20;Keep the view open for the steps below.

</Aside>

### Add the Integration Details within Entra ID

In Entra ID, follow the steps below to complete the configuration:

1. Click **Provisioning** from the left navigation menu of the created app.

2. Click **Connect your application**.

3. Copy over the following details from OnceHub:

   |                 |                                            |
   | --------------- | ------------------------------------------ |
   | **In Entra ID** | **In OnceHub**                             |
   | Tenant URL      | Base URL                                   |
   | Secret Token    | Secret Key (Click **Generate secret key**) |

4. Click Test connection.

5. Click Create to finish configuring the application.

With your integration complete, you can begin using Entra ID to automate your OnceHub user management.
