This guide provides a comprehensive **feature comparison between Booking Calendars and Booking Pages**. Use these comparison tables to understand the functional differences, unique advantages and configuration options available in Booking Calendars and Booking Pages.

## 1. The Core Transformation

This section compares the fundamental structural differences between the Booking Calendars and Booking Pages, focusing on how Booking Calendars consolidate configuration into a single, standalone object compared to the Booking Pages. It also highlights exclusive, high impact features such as centralized template control and AI driven Phone Booking that are available exclusively in Booking Calendars.

### Objects:

| **Feature Name**      | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                                                      |
| --------------------- | --------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Standalone Scheduling | Yes                   | No                 | **Booking Calendars:** Are standalone objects that configure all aspects (attendees, availability, forms) in one place. **Booking Pages:** Require separate Event Type objects. |

### Account Level Settings

| **Feature Name** | **Booking Calendars** | **Bookings Pages** | **Additional Information** |
| ---------------- | --------------------- | ------------------ | -------------------------- |
| Alert Center     | Yes                   | Yes                |                            |

### Booking Calendars Exclusive Features

These features are optimized in the Booking Calendars and are not available in Booking Pages.

| **Feature Name**                                                                                                    | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------- | --------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Phone Screening (Answer questions on routing forms)                                                                 | Yes                   | No                 | **Booking Calendars:** Integrated screening via routing forms before a meeting is booked.                                                  |
| Video Backgrounds (Elevate brand throughout scheduling)                                                             | Yes                   | No                 | **Booking Calendars:** Support for immersive video backgrounds on the booking interface.                                                   |
| Meeting Reassignment (Assign a scheduled meeting to a different host)                                               | Yes                   | No                 | **Booking Calendars:** Move existing meetings to different hosts or locations seamlessly.                                                  |
| Room & Resource Sync (Native organizational room directory)                                                         | Yes                   | No                 | **Booking Calendars:** Automatically reserves physical rooms from your directory for every booking.                                        |
| Reschedule on Behalf ( Guest rescheduling)                                                                          | Yes                   | No                 | **Booking Calendars:** Admins can reschedule meetings during a live conversation with a guest.                                             |
| Meeting Overlap (Mark yourself available after a booking, allowing overlapping meetings to maximize your schedule)  | Yes                   | No                 | **Booking Calendars:** Option to ignore specific scheduled meetings to allow new bookings at the same time.                                |
| Additional Guest Data (Capture info for extra guests)                                                               | Yes                   | No                 | **Booking Calendars:** Collect name, email, and relationship status for all additional attendees.                                          |
| Unlimited Busy Times (Sync all secondary calendars)                                                                 | Yes                   | No                 | **Booking Calendars:** Retrieve availability from an unlimited number of secondary calendars.                                              |
| Template Enforcement (Require that all new booking calendars to be created from templates)                          | Yes                   | No                 | **Booking Calendars:** Admins can mandate that all new Booking Calendars follow a strict brand template.                                   |
| Centralized Control (Lock key settings in templates and automatically push changes to all linked Booking Calendars) | Yes                   | No                 | **Booking Calendars:** Updating a template automatically updates all linked Booking Calendars.                                             |
| Concurrent Sessions (Automatically allow multiple bookings per host per time slot, each as a separate meeting)      | Yes                   | No                 | **Booking Calendars:** Allow multiple independent bookings (e.g., 3 separate guests) for the exact same time slot on one Booking Calendar. |
| Selection-based Location (Guest chooses the meeting address)                                                        | Yes                   | No                 | **Booking Calendars:** Allows the guest to choose between multiple physical addresses for a single time slot.                              |
| Optional Co-hosts (Add team members without restriction)                                                            | Yes                   | No                 | **Booking Calendars:** Allows co-hosts to be included in a meeting link without their availability being mandatory for the slot to appear. |
| Ad-hoc Co-hosts (Create a one-off multi-host meeting by adding co-host emails to the URL)                           | Yes                   | No                 | **Booking Calendars:** Enables the addition of co-hosts dynamically by appending parameters to the booking URL.                            |
| Booking without Email                                                                                               | Yes                   | No                 | **Booking Calendars:** Enables bookings using only a phone number.                                                                         |
| Phone Booking (Guests can book appointments using natural, everyday language)                                       | Yes                   | No                 | **Booking Calendars:** Exclusive AI-driven assistant that handles voice-to-booking conversations.                                          |
| Capacity Report (Plan staffing level with insights on future capacity, current usage, and past trends)              | Yes                   | No                 | **Booking Calendars:** Provides data on host utilization and seat availability for Group or Concurrent sessions.                           |
| Modern UI/ UX                                                                                                       | Yes                   | No                 | **Booking Calendars:** Interface is fully responsive and uses a newer design.                                                              |
| Modern Tech Stack (Blazing fast booking experience)                                                                 | Yes                   | No                 | **Booking Calendars:** Built on a modern infrastructure for significantly faster load times.                                               |

## 2. The Guest Experience (Front-end Settings)

This section explains how each one of them shapes the customer’s booking journey. This section covers the front-end configurations including location options, time slot settings, localization and the visual branding feature used to customize the guest interface.

### Location:

| **Feature Name**                                                    | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                                                             |
| ------------------------------------------------------------------- | --------------------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Virtual                                                             | Yes                   | Yes                | **Booking Calendars:** Can support multiple options for the guest to choose from, such as Native Zoom, Teams, Google Meet integration.                                                 |
| Physical/ In-person location (Multiple physical addresses per slot) | Yes                   | Yes                | **Booking Calendars:** Allows multiple physical addresses per slot. Hybrid support at calendar and profile level. **Booking Pages:** Use **Event Types** to offer different locations. |
| Phone                                                               | Yes                   | No                 | **Booking Pages:** Have indirect options for Phone location. Booking Calendars: Guest phone only (no host phone option).                                                               |
| Other                                                               | No                    | Yes                | **Booking Calendars:** Doesn’t support other locations directly at the moment but physical location can be used for the same.                                                          |

### Time Slot Settings

| **Feature Name**                                                                                                  | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                                                                                                                              |
| ----------------------------------------------------------------------------------------------------------------- | --------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Duration (Fixed)                                                                                                  | Yes                   | Yes                |                                                                                                                                                                                                                                                         |
| Multiple Durations (Offer different meeting length options)                                                       | Yes                   | Yes                | **Booking Calendars:** Allows up to 4 pre-defined durations in one calendar. **Booking Pages:** Uses multiple **Event Types / Booking Pages** to offer multiple duration options to the user.                                                           |
| Starting Times                                                                                                    | Yes                   | Yes                | **Booking Calendars:** Available in 15 min resolution.                                                                                                                                                                                                  |
| Time slot spacing (Define gaps between available slots)                                                           | Yes                   | Yes                |                                                                                                                                                                                                                                                         |
| Buffer Time (Add time for preparation and cleanup before and after meetings)                                      | Yes                   | Yes                |                                                                                                                                                                                                                                                         |
| Time Frame Rules (Set lead time booking limits)                                                                   | Yes                   | Yes                | **Booking Calendars:** Lead time (Avoid surprises with lead time set by minutes, hours or days) and Time frame limit.                                                                                                                                   |
| Time Zone Conversion (Time slots convert to your guest's local time, seamlessly established through conversation) | Yes                   | Yes                | **Booking Calendars:** Uses time zone conversion without prompt.                                                                                                                                                                                        |
| Time Zone Locking (Disable guest time zone change)                                                                | No                    | Yes                | **Booking Pages:** Allow admins to lock the timezone to the host's location                                                                                                                                                                             |
| Workload Rules (Limits total daily meetings allowed)                                                              | Yes                   | Yes                | **Booking Calendars:** Workload Rules can be defined at the Booking Calendar level for the hosts. **Booking Pages:** Implemented via Event Types.                                                                                                       |
| No. of time slots offered per day                                                                                 | No                    | Yes                | **Booking Calendars:** Doesn't support this at the moment, but setting up [**time slot spacing**](/product/booking-calendars/booking-settings/booking-calendar-timeframe-and-timeslot-preferences) can achieve the same outcome in most cases. |
| Show slot only during guest working hours                                                                         | Yes                   | Yes                | **Booking Calendars:** Show night-time indications on the guest front.                                                                                                                                                                                  |

### Sharing

| **Feature Name**                                                | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                |
| --------------------------------------------------------------- | --------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| Personalize Link                                                | Yes                   | Yes                | **Booking Calendars:** Have personalized link via URL parameters. **Booking Pages:** Have a personalized link via UI.     |
| One Time Links (Link expires after scheduling a single meeting) | Yes                   | Yes                | **Booking Calendars:** Supported natively. (**Note:** Not compatible with Hubs) **Booking Pages:** Only via Master Pages. |
| Share and publish                                               | Yes                   | Yes                | **Booking Calendars:** We share a page.                                                                                   |
| Chrome extension                                                | Yes                   | Yes                |                                                                                                                           |
| Website Embedding (Embed the booking action in your website)    | Yes                   | Yes                |                                                                                                                           |

### Localization

| **Feature Name**           | **Booking Calendars** | **Bookings Pages** | **Additional Information** |
| -------------------------- | --------------------- | ------------------ | -------------------------- |
| 24 hr format support       | Yes                   | Yes                |                            |
| Automatic Language support | No                    | No                 |                            |
| Custom language support    | Yes                   | Yes                |                            |

### Categories

| **Feature Name** | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                                                   |
| ---------------- | --------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Categories       | Yes                   | Yes                | **Booking Calendars:** External categories can be presented to guests within the Booking Hub. Whereas, internal categories (folders) for organizing links are not available. |

### Theme Designer

| **Feature Name** | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                                                                                                                                                                                                       |
| ---------------- | --------------------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Theme Designer   | Yes                   | Yes                | **Booking Calendars:** Features a real-time **WYSIWYG** (What You See is What You Get editor for desktop and mobile) editor for instant custom branding previews. Using **Booking Calendar Templates** allows you to centrally control the design. **Booking Pages:** Configuration is available centrally at the account level. |

## 3. Meeting Logistics & Rules

This section helps you explore the logic and rules that govern your scheduling workflows. This section elaborates how both the platforms handle availability, user level settings, meeting lifecycle management (like rescheduling and cancellations), and advanced scheduling options such as group sessions.

### Availability

| **Feature Name**                          | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                            |
| ----------------------------------------- | --------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| Recurring Availability with Date Specific | Yes                   | Yes                | **Booking Calendars:** Recurring is referred to as Weekly Working Hours and Date Specific Overrides (change hours for specific days). |

### User Level Settings

| **Feature Name**               | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                     |
| ------------------------------ | --------------------- | ------------------ | ---------------------------------------------------------------------------------------------- |
| Scheduled meeting availability | Yes                   | Yes                | **Booking Calendars:** Scheduled meeting availability and **location** can both be configured. |
| User Integrations              | Yes                   | Yes                |                                                                                                |

### Scheduling Options

| **Feature Name**                                                              | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                           |
| ----------------------------------------------------------------------------- | --------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Booking with Approval                                                         | Yes                   | Yes                | **Booking Calendars:** In some instances, using a Routing Form or Chatbot with screening or qualification questions can be an effective alternative. |
| Session Packages                                                              | No                    | Yes                | **Booking Calendars:** You may use Routing Forms or a redirect to guide a user through a flow where they book a series of calls sequentially.        |
| Group Sessions (Multiple guests book independently but join the same meeting) | Yes                   | Yes                |                                                                                                                                                      |

### Booking via Chatbots and Routing Forms

| **Feature Name**   | **Booking Calendars** | **Bookings Pages** | **Additional Information** |
| ------------------ | --------------------- | ------------------ | -------------------------- |
| Using interactions | Yes                   | Yes                |                            |

### Meeting Lifecycle

| **Feature Name**    | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                                                           |
| ------------------- | --------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Request reschedule  | Yes                   | Yes                | **Booking Calendars:** Users can also reschedule on behalf of the guest from within the platform.                                                                                    |
| Reassign            | Yes                   | Yes                | **Booking Pages:** Reassignment is limited to Google Calendar only.                                                                                                                  |
| Cancel              | Yes                   | Yes                |                                                                                                                                                                                      |
| Meeting owner/ Host | Yes                   | Yes                | **Booking Calendars:** Host settings define the meeting location, while the system **synchronizes** host and co-host schedules to show only common availability on the booking link. |
| Double Booking      | Yes                   | Yes                | **Booking Calendars:** Double booking happens through meeting overlap and Concurrent sessions.                                                                                       |

### Cancel/Reschedule Policy

| **Feature Name**                          | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                                                                                  |
| ----------------------------------------- | --------------------- | ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cancel/Reschedule Policy                  | No                    | Yes                | **Booking Calendars:** There is no dedicated policy field. However, information can be added to the **footer** or **welcome message**.                                                                      |
| Payment Linked Cancel/Reschedule Policies | No                    | Yes                | **Booking Calendars:** These must be communicated via custom text. For example, there is no direct way to refund money from Stripe integration. **Booking Pages:** Allow for policies coupled with payment. |
| Host Side Rescheduling                    | Yes                   | Yes                | **Booking Pages:** Hosts cannot conveniently reschedule on behalf of a guest.                                                                                                                               |

## 4. Team & Multi-User Management

This section helps you learn how to manage your team and collaborative scheduling scenarios. It focuses on multi-host panel meetings, automated distribution methods like Round Robin and Resource Pools and the administrative permissions required for different user roles.

### Panel Meetings

| **Feature Name**                                                                | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                         |
| ------------------------------------------------------------------------------- | --------------------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Multi-host support (Specific individuals assigned upfront as host and co-hosts) | Yes                   | Yes                | **Booking Calendars:** Use multi-host settings to include co-hosts in one link. **Booking Pages:** Require a master page setup for panel meetings. |

### Resource Pool

| **Feature Name**                                                                      | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                               |
| ------------------------------------------------------------------------------------- | --------------------- | ------------------ | -------------------------------------------------------------------------------------------------------- |
| Round Robin Distribution (Evenly distributes meetings across all members of the team) | Yes                   | Yes                | **Booking Calendars:** Offer a more simplified setup within the calendar itself.                         |
| Pooled Availability (Combined team schedule views)                                    | Yes                   | Yes                | **Booking Calendars:** Managed via **Teams** feature. **Booking Pages:** Managed via **Resource Pools**. |
| Any Available Team Member(with priority)                                              | Yes                   | Yes                |                                                                                                          |

### Access and Permissions

| **Feature Name** | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                           |
| ---------------- | --------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| Account owner    | Yes                   | Yes                |                                                                                                                                      |
| Admin            | Yes                   | Yes                | **Booking Calendars:** There is no such concept of Editor.                                                                           |
| Team Manager     | Yes                   | Yes                |                                                                                                                                      |
| Member           | Yes                   | Yes                | **Booking Calendars:** Member and Team Manager will be a viewer to the Booking Calendar of which they are part of but not as a host. |

## 5. Communications & Automation

This section helps you to compare how both Booking Calendars and Booking Pages handle data collection and messaging. It also helps you understand booking form behaviors, the use of tags for data filtering and the customization options for host and guest’s email and SMS notifications. It also reviews payment gateway support for Stripe and PayPal.

### Booking Form Behavior

| **Feature Name**                                                          | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                           |
| ------------------------------------------------------------------------- | --------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Automatic Redirect (Redirect to different web pages after booking action) | Yes                   | Yes                | **Booking Calendars:** Redirection occurs immediately **after booking** is completed.                                                                |
| Form Prefill (Auto populates guest data)                                  | Yes                   | Yes                | Both systems support pre-filling guest data via URL parameters to speed up the booking process.                                                      |
| Skip Booking Form                                                         | No                    | Yes                | **Booking Calendars:** To ensure data consistency and high-quality CRM integration, skipping the form is not supported in the Booking Calendar flow. |

### Tags:

| **Feature Name** | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                                          |
| ---------------- | --------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tags             | Yes                   | Yes                | **Booking Calendars:** Booking Hubs can be filtered using user attributes (Assign attributes to users based on characteristics such as language, skills, location). |

### User Notifications

| **Feature Name**                                        | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                                        |
| ------------------------------------------------------- | --------------------- | ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Customized user notifications (Edit email and SMS text) | No                    | Yes                | **Booking Calendars:** Allow on/ off toggles for notifications. User notifications content is not customizable. **Booking Pages:** Allow full text customization. |

### Guest Notifications

| **Feature Name**       | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                       |
| ---------------------- | --------------------- | ------------------ | ---------------------------------------------------------------- |
| Custom Email Templates | Yes                   | Yes                | **Booking Calendars:** Customizing SMS content is not supported. |

### Payment and Pricing

| **Feature Name**                                      | **Booking Calendars** | **Bookings Pages** | **Additional Information**                                                                                                                                                                                                                                                         |
| ----------------------------------------------------- | --------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Collect payment via PayPal & Direct Refund Capability | No                    | Yes                | **Booking Pages:** Supports secure payment collection via credit/ debit card or PayPal account during the booking flow. **Refund Policy:** Support direct or automatic refunds via the OnceHub interface.                                                                          |
| Collect payment via Stripe                            | Yes                   | No                 | **Booking Calendars:** Supports secure payment collection via credit/debit card or Stripe account during the booking flow. **Refund Policy:** Do not currently support direct or automatic refunds via the OnceHub interface; these must be handled manually via Stripe dashboard. |
