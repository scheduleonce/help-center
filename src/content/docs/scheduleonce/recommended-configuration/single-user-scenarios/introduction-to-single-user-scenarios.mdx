OnceHub allows you to offer multiple meeting types on your [Booking page](/scheduleonce/event-types-booking-pages/booking-pages/introduction-to-booking-pages "Introduction to Booking pages") or [Master page](/scheduleonce/master-pages-resource-pools/master-pages/introduction-to-master-pages "Introduction to Master Pages"). There are three ways to offer multiple meeting types using [Event types](/scheduleonce/event-types-booking-pages/event-types/introduction-to-event-types "Introduction to Event types"), Booking pages, and Master pages.

## Accept appointments for yoursel&#x66;**&#x20;**

If you accept appointments for yourself, Customers come to your Booking page and book appointments with you [automatically or with your approval](/scheduleonce/event-types-booking-pages/scheduling-options/automatic-booking-or-booking-with-approval "Automatic booking or Booking with approval"). If you offer only one meeting type, you can use an [Event type](/scheduleonce/event-types-booking-pages/event-types/introduction-to-event-types "Introduction to Event types") and link it to your [Booking page](/scheduleonce/event-types-booking-pages/booking-pages/introduction-to-booking-pages "Introduction to Booking pages").

For example, let’s say you offer a 60-minute tax return preparation session for a fee of $100. [Create an Event type](/scheduleonce/event-types-booking-pages/event-types/creating-an-event-type "Creating an Event type"), customize the settings to meet your requirements, and [associate it with a Booking page](/scheduleonce/event-types-booking-pages/booking-pages/adding-event-types-to-booking-pages "Adding Event types to Booking pages").

[Learn more about configuring your Event type](/scheduleonce/recommended-configuration/single-user-scenarios/accepting-appointments-for-yourself-using-event-types "Accepting appointments for yourself using Event types")

## Offer different appointment types on your Booking page

If you offer multiple meeting types which all have the same availability and same location, then all you need is one Booking page with multiple Event types linked to it. Each Event type can be a different meeting type with its own settings. You can configure the [Scheduling options](/scheduleonce/event-types-booking-pages/scheduling-options/introduction-to-scheduling-options "Introduction to the Scheduling options section"), [Time slots](/scheduleonce/event-types-booking-pages/timeslot-settings/introduction-to-time-slot-settings "Introduction to Time slot settings"), [Booking form](/scheduleonce/event-types-booking-pages/booking-forms-redirect/introduction-to-booking-form-and-redirect "Introduction to the Booking form and redirect section"), [Customer notifications](/scheduleonce/event-types-booking-pages/customer-notifications/introduction-to-customer-notifications "The Customer notifications section") and the [Payment and Cancel/Reschedule](/scheduleonce/event-types-booking-pages/event-types/payment-and-rescheduling "Event type: Payment and cancel/reschedule policy section") policies for each Event type.

For example, you might offer a 15-minute introductory session for free, a 30-minute online consultation session for $50 with a lenient reschedule/cancellation policy, and an hour long face-to-face consultation for $100 with a strict reschedule/cancellation policy. This is possible using multiple Event types with different configurations on your Booking page.

[Learn more about offering different appointment types](/scheduleonce/recommended-configuration/single-user-scenarios/offering-different-appointment-types-on-your-booking-page "Offering different appointment types on your Booking page")

## Use both Event types and multiple Booking pages together

[Event types](/scheduleonce/event-types-booking-pages/event-types/introduction-to-event-types "Introduction to Event types") and [Booking pages](/scheduleonce/event-types-booking-pages/booking-pages/introduction-to-booking-pages "Introduction to Booking pages") can be used together to meet a wide range of scheduling scenarios for offering Event types at different locations or at specific hours or days.

For example, let's say you're providing Event types in three locations and you're in different locations during different days of the week. Define the Event types that you provide and set each Booking page to be a location. You can set up your scheduling process so that Users will first select an Event type and then a location, or vice versa. In this specific scenario, you'll create the Booking pages and the Event types, link the Event types to the Booking pages, and then link the Booking pages to a Master page.

[Learn more about supporting different locations and times for your meetings](/scheduleonce/recommended-configuration/single-user-scenarios/supporting-different-locations-or-times "Supporting different locations or times")
