When updates are made to the ScheduleOnce API that are not compatible with the previous version, a new version is released.

The current version of the ScheduleOnce API is **v2** and is the version to use when integrating with Booking Pages.

## Version History

:::info[Current Version]

**v2** is the current version for all Booking Pages API integrations.
:::

## Backward Compatibility

When breaking changes are necessary, we release a new API version to ensure existing integrations continue to work without interruption. Previous versions remain supported to give you time to migrate at your own pace.
