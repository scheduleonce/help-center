You can import and export contacts from/to a CSV file using the **Import / Export** dropdown on the **Contacts** page.

---

## How to Import Contacts

Follow the steps below to import up to **7,000 contact records** at a time using a standard CSV file.

### Step 1: Select the File to Import

1. Navigate to **Contacts** from the left navigation menu.
2. Click the **Import / Export** dropdown in the top right corner.
3. Select **Import CSV**.
4. Drag and drop your CSV file into the upload area, or click **Select CSV File** to browse for the file.

### Step 2: Map the CSV Column Headers to Contact Properties

Once your CSV upload is complete, OnceHub automatically matches your **CSV columns** to **Contact Properties** based on the column headers.
If a column is not matched properly, select the appropriate contact property from the dropdown or create a new contact property.

### Step 3: Start the Import

Click **Start Import** from the bottom right corner to begin importing your records.

<Aside type="note">
  If a contact record already exists in OnceHub, the imported information
  updates the existing contact record instead of creating a duplicate record.
</Aside>

To learn more about how OnceHub recognizes duplicate contacts, see [**How Contacts Are Identified In OnceHub**](/contact-management/how-contacts-are-identified-in-oncehub/) article.

---

## How to View Imported Contacts

After the import is complete, you can view the newly added contact records by following these steps:

1. Expand **Imports** in the left sidebar.
2. Select the specific import file you want to view.

---

## How to Export Contacts

You can export your contact records to a CSV file for backup, import them into a third-party application, or use the data for reporting and analysis. Follow these steps to export your records:

1. Navigate to **Contacts** from the left navigation menu.
2. Click the **Import / Export** dropdown in the top right corner.
3. Select **Export CSV**.

Your contact records will download automatically as a CSV file.

---

## How to Export a Filtered List

To export a specific filtered list of contact records, apply your filters on the **Contacts page** before clicking **Export CSV**.

<Aside type="note">
  Your exported CSV file will only include the contact records matching your
  applied filters.
</Aside>
