## How to Map a Question to an Object Property

Each Booking Calendar allows you to configure which Questions will be saved into a property using the following steps:

1. Open the **Booking Calendar** you wish to edit.
2. Select the **Booking Form** tab.
3. Click the **+ Add Questions** pane in the top left.
4. Click or Drag & drop the desired Questions from the pane into the form.
5. Toggle on **Do More With This Answer**.
6. Select the **Object** and **Property** you want to map the question to.
7. Click **Save**

Once completed, the responses to the mapped questions will be automatically saved in OnceHub and can be included in integrations with tools like Salesforce, Hubspot, or Zapier.
