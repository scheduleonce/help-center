While **Phone Booking** requires no setup, there are a few unsupported features to be aware of:

## 1. Booking Form Questions

The type of questions guests are asked differs between the two methods:

|                   |                |                 |
| ----------------- | -------------- | --------------- |
| **Question Type** | **Phone Call** | **Web Browser** |
| Full Name         | Yes            | Yes             |
| Email Address     | Yes            | Yes             |
| Phone Number      | Yes            | Yes             |
| Free Text         | Yes            | Yes             |
| Single Select     | No             | Yes             |
| Multi Select      | No             | Yes             |
| Additional Guests | No             | Yes             |
| Attachment        | No             | Yes             |

## 2. Bookable Days

Phone Booking will not enforce the [**Booking Window**](/human-engagement/booking-calendars/booking-settings/booking-calendar-timeframe-and-timeslot-preferences#BookingWindow) if it is set to use **Bookable days**.
