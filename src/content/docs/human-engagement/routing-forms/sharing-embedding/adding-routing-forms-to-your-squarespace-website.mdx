Adding a routing form to your Squarespace website is quick and easy.

<Aside type="caution">

Adding custom javascript requires a **Squarespace** **Business** or **Commerce** plan.

</Aside>

## Add a routing form to your website

### Create the routing form

1. Go to **Routing forms** on the left.
2. Click on the **Create routing form** button OR duplicate another form by clicking the three dots menu for that form and selecting **Duplicate**.

[**Create the form**](/human-engagement/routing-forms/introduction-to-routing-forms/creating-routing-form) as you prefer, either duplicated from another, from scratch, or using a template.

When you've added the interactions you want, routed them, and designed the form as you like, navigate to the **Embed on website** tab.

### Install the code

#### In OnceHub

You'll grab the code you need for Squarespace.

1. On the **Publish** tab, select **Get the code**.
2. Copy the code.

#### In Squarespace

You'll add a [**code block**](https://support.squarespace.com/hc/en-us/articles/206543167-Code-blocks) on your website, on each individual page where you want a form.

1. Edit your website.
2. Click to [**add content with a block**](https://support.squarespace.com/hc/en-us/articles/206543757).
3. In the **Basic** section, select **Code**.
4. The selected **Mode** should be HTML.
5. Paste the code from OnceHub and adjust as needed.
6. Save your website.

That's it! Your website can now display your routing form in the place you added it.
