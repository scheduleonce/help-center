**Tip**

OnceHub recommends using [Event types](/introduction-to-event-types/ "Introduction to Event types") for [multiple Team members accepting appointments](/multiple-team-members-accepting-appointments-with-event-types/ "Multiple team members accepting appointments with Event types using Rule-based assignment")[.](/multiple-team-members-accepting-appointments-with-event-types/ "Multiple team members accepting appointments with Event types using Rule-based assignment") Event types allow you to offer several meeting types with different durations, price, and other properties on one [Booking page](/introduction-to-booking-pages/ "Introduction to Booking pages") or [Master page](/introduction-to-master-pages/ "Introduction to Master Pages").  

You can use OnceHub to accept bookings for multiple Team members. Team members can be accessed via one [Master page](/introduction-to-master-pages/ "Introduction to Master Pages") or independently via their individual Booking pages. [Learn more about User management](/introduction-to-user-management/ "Introduction to User Management")

# Requirements

You must be a [OnceHub Administrator](/user-type-member-vs-admin-team-manager/ "Differences between Administrator and Member") to set up this scenario. 

# How to set up

1.  Select your profile picture or initials in the top right-hand corner → Profile settings → **Users**.
2.  [Create a User account](/adding-users/ "Adding Users") for each Team member.
3.  You can [create a Booking page](/creating-a-booking-page/ "Creating a Booking page") for each Team member and make the Team member [the Owner of the page](/booking-page-ownership/ "Booking page ownership"). Alternatively, you can let the Team members create their own Booking pages. [Learn more about Booking pages](/introduction-to-booking-pages/ "Introduction to Booking pages")
4.  If you want to group the Booking pages under one page, you can [create a Master page](/master-page-setup-creating-a-master-page/ "Creating a Master page"). Make sure you select [Booking pages only (without Event types)](/booking-pages-only-without-event-types/ "Booking pages only (without Event types)") as your [Master page scenario](/master-page-scenarios/ "Master page scenarios").
5.   In the [Assignment section](/master-page-event-types-and-assignment-section/ "Master Page: Assignment section"), select the Booking pages you want to add to the Master page.
6.  If you have a lot of Team members, you might want to add [Tags](/using-booking-page-tags-in-master-pages/ "Using Booking page tags in Master pages") to your Booking pages so that Customers can find the person they want to book with in a fast and efficient manner. Tags enable Customers to filter Booking pages by keywords. [Learn more about Tags](/using-booking-page-tags-in-master-pages/ "Using Booking page tags in Master Pages")
7.  In addition, you can use [categories](/so-introduction-to-categories/ "Introduction to categories") to organize your Booking pages. Categories enable you to better model your scheduling scenarios. This results in a booking process that is faster, easier to navigate, and creates a better overall scheduling experience for your Customers. [Learn more about categories](/so-introduction-to-categories/ "Introduction to Categories")

You’re all set! To test your Master page, go to the [Master page Overview](/master-page-overview-section/ "Master page: Overview section") and make a test booking by using the public link in the **Share & Publish** section.
