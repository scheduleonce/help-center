OnceHub can be used to accept bookings for a class, workshop, or other type of Group sessions in which a maximum number of people are allowed to attend.

In this article, we will configure [Booking pages](/introduction-to-booking-pages/ "Introduction to Booking pages") for a virtual class.

When your OnceHub account is connected to [Zoom](/scheduleonce-connector-for-zoom/ "The ScheduleOnce connector for Zoom"), [Microsoft Teams](/the-scheduleonce-connector-for-microsoft-teams/), [GoToMeeting](/scheduleonce-connector-for-gotomeeting/ "The ScheduleOnce connector for GoToMeeting"), or [Webex Meetings](/scheduleonce-for-webex/ "The ScheduleOnce connector for Webex Meetings"), the virtual class meeting will be automatically created and scheduled in a single action. 

1.  [Create a new Booking page](/creating-a-booking-page/ "Creating a Booking page") for accepting bookings for the virtual class.
2.  In the [**Recurring availability**](/booking-page-recurring-availability-section/ "Booking page: Recurring availability section") section, erase recurring availability on the calendar.
3.  Next, go to the [**Date-specific availability**](/booking-page-date-specific-availability-section/ "Booking page: Date-specific availability section") section to mark the time/times for the class on the calendar.
4.  In the [**Scheduling options**](/introduction-to-the-scheduling-options-section/ "Introduction to the Scheduling options section") section, set the Group session option to "Unlimited," or to a defined capacity, if you want to limit the number of participants.
5.  Complete the rest of the [Booking page settings](/introduction-to-booking-pages/ "Introduction to Booking pages").
6.  If you want to list multiple classes, you can create a Booking page for each class and then group them under a [Master page](/introduction-to-master-pages/ "Introduction to Master Pages").
