Accepting bookings for webinars is a common use case. Here are specific instructions for creating the desired configuration:

You can use the OnceHub connectors for [Zoom](/scheduleonce-connector-for-zoom/ "The ScheduleOnce connector for Zoom"), [Google Meet](/the-scheduleonce-connector-for-google-meet/), [Microsoft Teams](/the-scheduleonce-connector-for-microsoft-teams/), [GoToMeeting](/scheduleonce-connector-for-gotomeeting/ "The ScheduleOnce connector for GoToMeeting"), and [Webex Meetings](/scheduleonce-for-webex/ "The ScheduleOnce connector for Webex Meetings") to set up and schedule webinars in one step.

1.  [Create a new Booking page](/creating-a-booking-page/ "Creating a Booking page") for accepting bookings for the webinar.
2.  In the [**Recurring availability**](/booking-page-recurring-availability-section/ "Booking page: Recurring availability section") section, erase recurring availability and save.
3.  Then go to the [**Date-specific availability**](/booking-page-date-specific-availability-section/ "Booking page: Date-specific availability section") section to mark the time/times for the webinar.
4.  In the [**Scheduling options**](/introduction-to-the-scheduling-options-section/ "Introduction to the Scheduling options section") section, set the Group session option to "Unlimited," or to a defined capacity, if you want to limit the number of participants.
5.  Complete the rest of the [Booking page settings](/introduction-to-booking-pages/ "Introduction to Booking pages").
6.  If you want to list multiple webinars, you can create a Booking page for each webinar and then group them under a [Master page](/introduction-to-master-pages/ "Introduction to Master Pages").
