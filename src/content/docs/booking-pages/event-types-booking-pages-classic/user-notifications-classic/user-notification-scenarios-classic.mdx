This table defines the User notification scenarios used in the [User notification section](/introduction-to-user-notifications/ "Introduction to User notifications section") of a [Booking page](/introduction-to-booking-pages/ "Introduction to Booking pages"). These scenarios are the booking events that can take place during a booking lifecycle. You can choose which scenarios will trigger notifications and if the notifications are sent via email, SMS, or both.  

The User notifications section can be found by going to **Booking pages** in the bar on the left → **Booking page → User notifications**.
